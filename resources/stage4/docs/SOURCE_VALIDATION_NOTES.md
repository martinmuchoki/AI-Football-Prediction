# Source Validation Notes — verified 2026-09-10

Reusable-stock/open-media policy references included in the seed register:

- Pexels: free use; attribution not required; modification allowed; third-party rights still matter.
- Pixabay: free use and modification subject to prohibited uses; standalone redistribution and some trademark uses are restricted.
- Coverr: free commercial/non-commercial use and modification; separate brand/trademark/property rights may apply.
- Mixkit: accept Stock Video Free License; reject Restricted License for commercial MDRN SportsQ use.
- Wikimedia Commons: verify the licence on every file description page.
- YouTube: only Creative Commons Attribution content is potentially reusable under CC BY; Standard YouTube licence is not reusable permission.
- Vimeo: Creative Commons terms vary by selected licence; commercial and derivative permissions must be checked.
- Europeana: evaluate the rights statement attached to each digital object.

Official football sources are for factual verification by default, not media reuse.
